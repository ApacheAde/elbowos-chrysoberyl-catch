# Chrysoberyl Catch

Full-colour Python 3 neon crystal catcher arcade for ElbowOS.

Steer the glowing paddle to catch falling chrysoberyl gems. Different colours score differently. Misses reduce lives.

## Play

```bash
pip install -r requirements.txt
python3 chrysoberyl_catch.py --play
```

Controls: ← → or A/D move the paddle. R restarts. Esc quits.

## Record a 9:16 reel

```bash
python3 chrysoberyl_catch.py --record
```

Produces a 15-second 1080x1920 H.264 MP4 with title, score and handle overlay.
